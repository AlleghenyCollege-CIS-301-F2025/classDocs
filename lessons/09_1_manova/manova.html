🚀 Review: Statistical Test Evolution

🔵 t-test

  • 👥 Groups: 2
  • 📊 Variables: 1 continuous
  • ❓ Question: Do two groups differ on one variable?
  • 💡 Example: Do males ♂️ and females ♀️ differ in height? 📏

🟢 ANOVA

  • 👥 Groups: 2+
  • 📊 Variables: 1 continuous
  • ❓ Question: Do multiple groups differ on one variable?
  • 💡 Example: Do different treatments affect blood pressure? 🩺

🟠 MANOVA

  • 👥 Groups: 2+
  • 📊 Variables: 2+ continuous
  • ❓ Question: Do multiple groups differ on multiple variables simultaneously?
  • 💡 Example: Do treatments affect both blood pressure 🩺 AND heart rate ❤️?

🤔 What is MANOVA?

🎯 Multivariate Analysis of Variance (MANOVA)

  • 🔄 Extension of ANOVA to multiple dependent variables
  • 🎯 Tests whether group means differ across multiple continuous variables simultaneously
  • 🔗 Considers correlations between dependent variables
  • 💪 More powerful than running separate ANOVAs when variables are correlated

🌟 Key Advantage: Controls for Type I error inflation when testing multiple variables

🌍 Real-world Applications:

  • 🧠 Psychology: Do therapy types affect anxiety 😰, depression 😢, and stress 😫 simultaneously?
  • 📱 Marketing: Do advertisements impact brand awareness 🧠, purchase intent 🛒, and satisfaction 😊?

🤚 MANOVA Assumptions Overview

🎯 Before Running MANOVA: Critical Assumptions to Check!

🔵 Fundamental Requirements

1️⃣ Independence of Observations 👥

2️⃣ Multivariate Normality 📊

3️⃣ Homogeneity of Covariance ⚖️

🟠 Additional Considerations

4️⃣ No Extreme Outliers 🎯

5️⃣ Adequate Sample Size 📈

6️⃣ Linear Relationships 📏

💡 Remember: Violating assumptions can lead to invalid conclusions! Always check before interpreting results. 🚨

1️⃣ Independence of Observations

🔵 What it means: Each observation should be independent of all other observations

✅ Good Examples:

  • 🦴 Different skulls from different individuals (our dataset!)
  • 👨‍🎓 Test scores from different students
  • 🏥 Patient outcomes from different hospitals
  • 🌱 Plant growth measurements from different plots

❌ Problematic Examples:

  • 📏 Multiple measurements from same individual
  • 👨‍👩‍👧‍👦 Family members (genetic correlation)
  • 🏫 Students within same classroom
  • 🕐 Repeated measures over time

🛠️ How to check: - Review study design 🔍 - Consider data collection methods 📝 - Ask: “Could one observation influence another?” 🤔

2️⃣ Multivariate Normality

🔵 What it means: Each group’s data should follow a multivariate normal distribution across all dependent variables

✅ Checking Methods:

  • 📊 Shapiro-Wilk test (per variable, per group)
  • 📈 Q-Q plots (visual assessment)
  • 🎯 Mardia’s test (multivariate)
  • 👁️ Histograms (quick visual check)

🚨 When Violated:

  • 📐 Skewed distributions
  • 📊 Heavy-tailed distributions
  • 🎯 Bimodal distributions
  • ⚡ Extreme outliers present

💡 Robustness Note: MANOVA is reasonably robust to normality violations with large samples (n > 30 per group), especially with equal group sizes! 🛡️

3️⃣ Homogeneity of Covariance Matrices

🔵 What it means: The covariance matrices should be equal across all groups (Box’s assumption)

🧮 Mathematical representation: \[\Sigma_1 = \Sigma_2 = \cdots = \Sigma_k\]

💡 What Equal Covariances Mean:

  • 📏 Similar variability (variance is measurement of the spread from the mean) across groups
  • 🔗 Similar correlations between variables
  • ⚖️ Consistent measurement precision

✅ Testing Methods:

  • 📊 Box’s M Test (most common)
  • 👁️ Visual inspection of covariance matrices
  • 📈 Levene’s test (for each variable individually)

3️⃣ Homogeneity: Testing & Robustness

🔵 What it means: The covariance matrices of the dependent variables are equal across all groups

⚠️ Box’s M Test Sensitivity:

  • Very sensitive to normality violations
  • Can reject even with minor differences
  • Consider practical significance
  • Often too strict in practice

** 🕺🏽 Robustness Guidelines:**

  • Robust with equal group sizes
  • Pillai’s trace most robust when violated
  • Consider Welch’s MANOVA alternatives
  • Violations often acceptable with n ≥ 30

4️⃣ No Extreme Outliers

🔵 What it means: Extreme values that could distort the analysis should be identified and addressed

✅ Detection Methods:

  • 📊 Mahalanobis Distance (multivariate)
  • 📈 Box plots (univariate)
  • 🎯 Scatterplot matrices (visual)

🚨 Types: - 📏 Univariate, 🎯 Multivariate, 🔄 Influential

🛠️ Handling Options:

  1. Investigate cause 🔍
  2. Transform if systematic 🔄
  3. Remove if error ❌
  4. Report separately if valid �

💡 Rule: Mahalanobis distance > χ²(p, 0.001) = potential outlier

5️⃣ Adequate Sample Size

🔵 What it means: Sufficient observations per group relative to number of dependent variables

✅ Guidelines:

  • 📊 Minimum: n > p per group
  • 🎯 Better: n ≥ 20 + p per group
  • 💪 Best: n ≥ 30 per group

🧮 Our Skulls Dataset:

  • 4 variables, 30 per epoch ✅
  • 30 > 24 (20+4) ✓ Excellent!

❌ Small Sample Issues:

  • Reduced power & reliability
  • Unreliable covariance estimates
  • Box’s M test problems

💡 Unequal Groups: Keep ratio < 4:1

6️⃣ Linear Relationships & Additional Considerations

🔵 Linear Relationships:

  • Variables should be linearly related 📊
  • Check with scatterplots
  • Transform if non-linear 🔄

✅ Ideal Correlations: r = 0.3 to 0.7 🔗

🚨 Avoid: - r < 0.3: Use separate ANOVAs - r > 0.9: Multicollinearity issues

🛡️ Most Robust: Pillai’s Trace Equal groups + n ≥ 30 = Better robustness ⚖️

🥷🏄🏻‍♂️ When to Use MANOVA

✅ Use MANOVA when:

🎯 You have 2+ groups (independent variable is categorical)

📊 You have 2+ continuous dependent variables

🔗 Variables are reasonably correlated (but not too highly)

🛡️ You want to control Type I error across multiple tests

❌ Don’t use MANOVA when:

🚫 Variables are completely uncorrelated (r ≈ 0)

🔗 Variables are too highly correlated (r > 0.9) - use one variable

1️⃣ You have only one dependent variable - use ANOVA

👥 Sample size is too small relative to number of variables

🎯 MANOVA Hypotheses

🔵 Null Hypothesis (H₀): The population mean vectors are equal across all groups

\[H_0: \boldsymbol{\mu}_1 = \boldsymbol{\mu}_2 = \cdots = \boldsymbol{\mu}_k\]

where \(\boldsymbol{\mu}_i = [\mu_{i1}, \mu_{i2}, \ldots, \mu_{ip}]\) is the mean vector for group i

🟠 Alternative Hypothesis (H₁): At least one group’s mean vector differs from the others

\[H_1: \text{Not all } \boldsymbol{\mu}_i \text{ are equal}\]

🗣️ So, Like, What Does That Mean? - H₀: All groups have the same average values across all measured variables 📊 - H₁: At least one group differs from others on at least one variable 🎯

🧮 MANOVA Test Statistics

MANOVA uses multiple test statistics (unlike ANOVA’s single F-statistic): 🆚

🔵 Wilks’ Lambda (Λ)

  • 📊 Most commonly reported
  • 📏 Ranges from 0 to 1
  • ⬇️ Smaller values = greater group differences

🟢 Pillai’s Trace

  • 🛡️ Most robust to assumption violations
  • 📏 Ranges from 0 to 1
  • ⬆️ Larger values = greater group differences

🟠 Hotelling-Lawley Trace

  • 💪 Most powerful when assumptions are met
  • 📏 Range: 0 to ∞
  • ⬆️ Larger values = greater group differences

🟣 Roy’s Greatest Root

  • 🎯 Most powerful for detecting differences in one dimension
  • ⚠️ Can be liberal (Type I error)

✅ Assumption Check: Egyptian Skulls Dataset

Let’s verify our dataset meets MANOVA assumptions:

1. Independence of Observations ✅ - Different skulls from different individuals and time periods - No repeated measures or clustering

2. Multivariate Normality 🤔 - Need to test with Shapiro-Wilk or Mardia’s test - Visual inspection with Q-Q plots

3. Homogeneity of Covariance Matrices ⚠️ - Should test with Box’s M test - May be violated but MANOVA is reasonably robust

4. No Extreme Outliers 👀 - Visual inspection suggests some potential outliers - Should check with Mahalanobis distance

Practical Guidelines

Choosing Test Statistics:

Wilks’ Lambda

  • Default choice
  • Good balance of power and robustness
  • Most commonly reported in literature

Pillai’s Trace

  • Use when assumptions are violated
  • Most robust option
  • Conservative (less Type I error)

Hotelling-Lawley

  • Use when assumptions are clearly met
  • Most powerful option
  • Can be sensitive to violations

Roy’s Greatest Root

  • Use when expecting differences in one primary dimension
  • Can be liberal (more Type I error)

Effect Size in MANOVA

# Calculate eta-squared for overall effect
skulls_aov <- summary.aov(skulls.manova)

# Extract sums of squares for effect size calculation
# This is a simplified approach
cat("Effect sizes (eta-squared) for each variable:\n")
Effect sizes (eta-squared) for each variable:
for(i in 1:4) {
  aov_summary <- skulls_aov[[i]]
  ss_effect <- aov_summary[1, "Sum Sq"]  # Sum of squares for epoch
  ss_total <- sum(aov_summary[, "Sum Sq"])  # Total sum of squares
  eta_sq <- ss_effect / ss_total
  var_name <- c("mb", "bh", "bl", "nh")[i]
  cat(paste(var_name, ": ", round(eta_sq, 3), "\n"))
}

📊 Interpreting Effect Sizes

🔵 Eta-squared (η²) Guidelines:

  • 📏 Small: η² = 0.01 (1% of variance)
  • 📊 Medium: η² = 0.06 (6% of variance)
  • 📈 Large: η² = 0.14 (14% of variance)

✅ Our Results Show:

  • All variables have medium to large effects
  • Epoch explains 10-20% of variance
  • Substantial evolutionary changes! 🧬

💡 What This Means:

  • 🏺 Historical periods significantly shaped skull morphology
  • 📏 Maximum breadth shows strongest effect
  • 🎯 Practical significance beyond statistical significance

🚨 Remember: Effect size ≠ Statistical significance Both are needed for complete interpretation! 🔍

Common Mistakes to Avoid

❌ Running multiple ANOVAs instead of MANOVA - Inflates Type I error - Ignores variable correlations

❌ Using MANOVA with uncorrelated variables - No advantage over separate ANOVAs - Wastes statistical power

❌ Ignoring assumptions - Can lead to incorrect conclusions - Always check assumptions first

❌ Stopping at significant MANOVA - Need follow-up analyses to understand which groups/variables differ - MANOVA is just the first step!
