🌳 What is a Decision Tree?

Think of it like a game of “20 Questions”! 🎮

  • Start at the root (top)
  • Ask a yes/no question at each node
  • Follow the branches based on answers
  • Reach a leaf (conclusion) at the bottom

Real-life Example: “Should I bring an umbrella?” 🌂

  • Is it cloudy? → Yes → Will it rain? → Yes → Bring umbrella!

Decision Tree Structure:

        [Is it cloudy?]
           /        \
         Yes         No
         /             \
   [Will rain?]    [Don't bring]
      /    \
    Yes     No
    /         \
[Bring!]  [Maybe bring]

Key Terms:

  • 🌱 Root Node: Starting point
  • 🌿 Internal Nodes: Decision points
  • 🍃 Leaf Nodes: Final outcomes
  • 🌿 Branches: Connections between nodes

🎯 Why Use Decision Trees?

  • 🚀 Advantages
  • ⚠️ Limitations
  • 💡 Best Use Cases
  • ✅ Easy to understand - Visual and intuitive!
  • ✅ No data prep needed - Works with raw data
  • ✅ Handles mixed data - Numeric & categorical
  • ✅ Non-parametric - No assumptions about data distribution
  • ✅ Feature importance - Shows which variables matter most
  • ✅ Quick to train - Fast even on large datasets
  • ❌ Overfitting risk - Can memorize training data
  • ❌ Unstable - Small data changes = different tree
  • ❌ Biased to dominant classes - Imbalanced data issues
  • ❌ Not always optimal - Greedy algorithm
  • ❌ Struggles with linear relationships

Perfect for:

  • 🏥 Medical diagnosis (disease present/absent?)
  • 💳 Credit approval (approve/reject loan?)
  • 📧 Spam detection (spam/not spam?)
  • 🎓 Student performance (pass/fail?)
  • ⚽ Sports outcomes (win/lose/draw?)
  • 🐾 Species classification (cat/dog/rabbit?)

🔬 How Decision Trees Work: The Algorithm

Step-by-Step Process:

  1. Start with all data at the root node 🌱
  2. Find the best split - Which feature separates classes best?
    • Measure “purity” using Gini Index or Information Gain
  3. Split the data into subgroups based on that feature
  4. Repeat for each subgroup (recursively!)
  5. Stop when:
    • All samples in a node are the same class ✅
    • Maximum depth reached 📏
    • Too few samples to split 🔢

Key Concept: Splitting Criteria 📊

Gini Index: Measures impurity (0 = pure, 0.5 = mixed)

Information Gain: Reduction in entropy (uncertainty)

The algorithm picks the split that gives the best improvement!

Reading the Output 📖

  • node): Node number in the tree
  • split: The condition used to split this node
  • n: Number of observations at this node
  • loss: Number of misclassifications
  • yval: Predicted class for this node

📊 Understanding the Model Output

Let’s decode what print(animal_model) shows us:

The output displays a text representation of the decision tree structure:

n=20  (total number of observations)

node), split, n, loss, yval, (yprob)
      * denotes terminal (leaf) node

Key Components:

  • Node number: Each decision point gets a unique ID
  • Split condition: The rule used (e.g., “size=large,medium”)
  • n: How many animals reach this node
  • loss: How many would be misclassified using this node’s prediction
  • yval: The predicted class (cat, dog, bird, rabbit)
  • yprob: Probability distribution across all classes

📖 Reading a Node Example

Example from the output:

1) root 20 10 dog (0.25 0.50 0.15 0.10)
2) size=large,medium 12  2 dog (0.17 0.83 0.00 0.00) *

Breaking it down:

Node 1 (root):

  • 20 observations total
  • 10 misclassifications if we guess “dog” for everyone
  • Predicts dog as most common class
  • Probabilities: 25% cat, 50% dog, 15% bird, 10% rabbit

Node 2:

  • Animals with size=large,medium
  • 12 observations reached this node
  • Only 2 misclassifications (pretty good!)
  • Predicts dog with 83% probability
  • * means this is a terminal node (no further splits)

🔍 Interpreting the Tree

Reading the Animal Tree: 📖

  1. Root Node: Starts with all animals
  2. First Split: “Is size = large?”
    • Yes → Likely a dog (large animals)
    • No → Continue asking questions
  3. Second Split: “Is size = small?”
    • Yes → Check color next
    • No (medium) → Likely a dog
  4. Leaf Nodes: Final predictions
    • Small + brown/gray → cat
    • Small + white/orange → bird or rabbit

🌳 Building the Titanic Model

# Build decision tree for Titanic survival
titanic_model <- rpart(
  Survived ~ Pclass + Sex + Age + Fare + SibSp + Parch,
  data = titanic_data,
  method = "class",
  control = rpart.control(cp = 0.02)  # Complexity parameter
)

Model Configuration ⚙️

We’re using cp = 0.02 to prevent overfitting. This creates a balanced tree that’s complex enough to be useful but simple enough to generalize well.

🔧 Tuning Decision Trees: Control Parameters

Important rpart.control() parameters:

control = rpart.control(
  cp = 0.01,        # Complexity parameter
  minsplit = 20,    # Min observations to split
  minbucket = 7,    # Min observations in leaf
  maxdepth = 10     # Maximum tree depth
)

Parameter Effects:

  • Lower cp → more complex tree
  • Higher minsplit → simpler tree
  • Higher minbucket → fewer, larger leaves

Balance Complexity! ⚖️

Too simple = underfitting (misses patterns). Too complex = overfitting (memorizes noise). Finding the sweet spot is key!

🔧 Comparing Tree Complexities

Why Prune? ✂️

Complex trees overfit! They memorize training data instead of learning patterns. Pruning simplifies the tree for better predictions on new data.

Choosing the right CP:

  • Look for the CP with lowest xerror (cross-validation error)
  • Or use the “1-SE rule” for simpler trees
  • nsplit: Number of splits in the tree
  • rel error: Relative error on training data
  • xerror: Cross-validated error
  • xstd: Standard deviation of xerror

Cross-Validation Matters! 🔄

The xerror is more reliable than training error because it tests on data the tree hasn’t seen. Always trust xerror over rel error!

✂️ Applying Pruning

# Find optimal CP
optimal_cp <- complex_tree$cptable[which.min(complex_tree$cptable[,"xerror"]),"CP"]

# Prune the tree
pruned_tree <- prune(complex_tree, cp = optimal_cp)

🔬 Understanding Split Quality

How does the algorithm choose splits?

Gini Index:

  • Formula: \(Gini = 1 - \sum_{i=1}^{n} p_i^2\)
  • Perfect split: Gini = 0 (all same class)
  • Worst split: Gini = 0.5 (50/50 mix)
  • Goal: Minimize Gini after split

Information Gain:

  • Formula: \(IG = Entropy(parent) - \sum \frac{|child|}{|parent|} \times Entropy(child)\)
  • Entropy: \(H = -\sum_{i=1}^{n} p_i \log_2(p_i)\)
  • Pure node: Entropy = 0
  • Goal: Maximize information gain

Gini vs Information Gain 🤔

Both methods usually produce similar trees! Gini is slightly faster to compute, while Information Gain has a theoretical foundation in information theory. rpart uses Gini by default.

🎯 Best Practices & Tips

Key recommendations for building decision trees:

  • ✅ Start simple - Use default parameters first
  • ✅ Check class balance - Adjust priors if needed
  • ✅ Cross-validate - Don’t trust training accuracy alone
  • ✅ Prune wisely - Simpler trees generalize better
  • ✅ Interpret carefully - Correlation ≠ Causation
  • ✅ Feature engineering - Good features = better trees
  • ✅ Ensemble methods - Consider Random Forests
  • ✅ Visualize always - Trees are meant to be seen!

Common Pitfall: 🚨 Don’t overfit! A tree that’s 100% accurate on training data is probably memorizing!

The Golden Rule ⚖️

If your training accuracy is much higher than test accuracy, you’re overfitting! Increase cp, minsplit, or try pruning.

# ============================================
# COMPLETE DECISION TREE WORKFLOW
# ============================================

# 1. Load libraries
library(rpart)
library(rpart.plot)
library(tidyverse)

# 2. Load and prepare data
data(titanic_train, package = "titanic")
df <- titanic_train %>% select(Survived, Pclass, Sex, Age, Fare) %>% na.omit()

# 3. Split train/test
set.seed(42)
train_idx <- sample(1:nrow(df), 0.7 * nrow(df))
train <- df[train_idx, ]
test <- df[-train_idx, ]

# 4. Build model
model <- rpart(Survived ~ ., data = train, method = "class",
               control = rpart.control(cp = 0.01))

# 5. Visualize
rpart.plot(model, main = "Titanic Survival Tree", box.palette = "RdYlGn")

# 6. Evaluate
pred <- predict(model, test, type = "class")
accuracy <- mean(pred == test$Survived)
cat("Test Accuracy:", round(accuracy * 100, 2), "%\n")

# 7. Prune if needed
pruned <- prune(model, cp = 0.02)
rpart.plot(pruned, main = "Pruned Tree")
